THE PROBLEM:
------------
Render tried to deploy using commit 51b0401b which contains:
    COPY docker/apache.conf /etc/apache2/sites-available/000-default.conf
    
This file doesn't exist in Git, causing the build to fail.

THE SOLUTION:
-------------
The Dockerfile has been simplified and fixed locally. 
Now you just need to COMMIT and PUSH it!

================================================================================
                              🎯 WHAT TO DO NOW
================================================================================

STEP 1: RUN THIS SCRIPT
------------------------
Windows:
    deploy-fix.bat

Linux/Mac:
    chmod +x deploy-fix.sh
    ./deploy-fix.sh

OR MANUALLY:
    git add Dockerfile
    git commit -m "Fix: Remove docker/apache.conf dependency"
    git push origin main

--------------------------------------------------------------------------------

STEP 2: VERIFY ON GITHUB
-------------------------
Visit: https://github.com/aymen-benmerrouche/TALEBDZ/blob/main/Dockerfile

✅ Should NOT see: COPY docker/apache.conf
✅ Should see: RUN echo '<VirtualHost *:80>

--------------------------------------------------------------------------------

STEP 3: DEPLOY ON RENDER
-------------------------
1. Go to: https://dashboard.render.com/
2. Select your TalebDZ service
3. Click: "Manual Deploy" → "Deploy latest commit"
4. Wait 3-5 minutes for build to complete

--------------------------------------------------------------------------------

STEP 4: VERIFY IT WORKS
------------------------
Test your live URL:
    https://your-app.onrender.com/

Should show:
    ✅ Homepage loads
    ✅ CSS and images display
    ✅ No 500 errors
